## 本轮已完成的视觉重构与体验优化内容

### 1. 顶栏长文件名排版自适应美化
*   **限宽截断**：新增 `.headerFilename` 样式（`max-width: 200px`、`ellipsis` 截断），长文件名悬浮显示完整 `title`，彻底解决了文件名过长把分辨率、时长、段数等重要元数据挤压到不可见区域的 Bug。

### 2. 控制键视觉层级分离与 macOS 分段选择器改造
*   **分段模式选择**：将原“快速模式”与“高精模式”大按钮，改造成包裹于 `.modeToggleGroup` 容器中的紧凑分段选择器，呈现精美半透明毛玻璃底板效果。
*   **主行动高亮**：“运行切片”动作按钮变更为 `variant="primary"` 蓝色高亮，拉开视觉重点。
*   **配置精简化**：弃用大段字样的 `重跑时保留/覆盖人工校准` 按钮，重构为 `<Checkbox>` 复选框直接嵌在模式右侧，极大节省空间。
*   **全操作浮层 Tooltip 补偿**：为所有镜头操作按钮（合并、拆分、确认）与切片模式控制按钮补充详细的 `title` 属性，鼠标悬停时提供清晰的文字功能解析。

### 3. 切片时间轴（SegmentTimeline） contiguous 胶片条无缝化
*   **缝隙缝合**：将原先断裂的格子间距 `gap` 缝合为 `1px`，去除每段小色块的圆角，使其像一段连续的电影胶带。
*   **内阴影高亮**：激活的镜头段不再使用外描边 border，改用内发光 `box-shadow: inset 0 0 0 1.5px #d6a95f`，消除高亮状态切换引起的任何布局微小位移。
*   **播放指针浮层层级**：`.timelinePlayhead` 引入 `z-index: 10`，防止被紧凑色块遮挡。

### 4. 关键帧 Gallery 按镜头段结构化分组与防呆说明
*   **按段归纳分组**：不再使用 300 张图片无序铺满一整页的 flat list，改造成由 `镜头段 #1`、`镜头段 #2` 组成的按段分组纵向 Section 列表。
*   **虚线框占位符**：未提取关键帧的段落显示精致的虚线空状态卡片，提示用户提取。
*   **防呆一键提取提示**：加粗说明“自动为视频中的**所有镜头段**一键提取，无需逐个处理”，打消了用户对上百个片段可能需要繁琐逐段操作的恐惧。

### 5. 双栏解耦与技术信息收纳
*   工作台彻底移除了右侧栏 `<aside>` 元素，将原先只读的“源文件”、“素材编号”等技术元数据存放入主内容下方的 `<details>`（“技术信息”）折叠区块内，在极致扩展工作区宽度的同时保留了所有重要后台属性。

*   **当前状况**：此模式仍是 Hybrid Fallback，重跑切片仍是由 mock 逻辑或快速逻辑降级模拟。
