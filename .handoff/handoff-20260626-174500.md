## 最终调试产物结构

```text
sceneforge/remix/source-assets/{sourceAssetId}/debug/
  shot_detection_result.json
  clip_generation_report.json
  keyframe_report.json
  runtime_diagnostics.json
  progress_events.jsonl
```

用途：

```text
shot_detection_result.json
  检查 fast/accurate 检测、fallback、边界、低置信度片段。

clip_generation_report.json
  检查 source_clip.mp4 生成数量、耗时、失败项。

keyframe_report.json
  检查 first/middle/last 抽帧来源、seek 时间、输出路径。

runtime_diagnostics.json
  检查 Python / TransNetV2 模型资产配置与解析结果。

progress_events.jsonl
  串联每个报告写入事件，用于人工排查流程执行进度。
```
