## 9. 代码与架构固定边界

- `electron/sceneforge/pipeline/scene-stage-definitions.ts` 是阶段和 requiredArtifacts 真相源。
- Runtime Prompt 真相源是 `prompts/sceneforge/stages/*`，不是外部 `.agents/skills`。
- Runner 只生成草案，不写 Artifact Store。
- 所有写回统一经过 `sceneSubmitStageDraft`、validator、approval、handoff。
- 普通 Continue 不自动运行；只有显式 Continue & Run 才运行下一阶段。
- Renderer 不得运行时 import `electron/**`；共享纯逻辑放 `src/sceneforge/lib/`。
- 手工 Markdown 是所有 support Direct LLM 阶段的降级路径，不得删除。
- 不添加需求外的自动全链、自动提交或隐式 API 消耗。
- 单文件尽量控制在 400–500 行；关键业务边界用中文注释解释“为什么”。
