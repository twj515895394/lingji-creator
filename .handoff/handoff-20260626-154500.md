## 一、上一份 handoff 关键背景

上一份 handoff 已完成真实分镜切片整体设计，核心结论：

1. 不建议整库接入 `transnetv2Pro`，只参考其处理链路。
2. Hugging Face `magnusdtd/TransNetV2` 更适合作为 PyTorch 模型资产来源。
3. `.pth` 只是权重，不能单独运行，必须配套 PyTorch 模型结构代码。
4. Remix 镜头切割必须生成真实可复用的 `source_clip.mp4`。
5. 实施阶段为：

```text
Phase 0：TransNetV2 模型资产准备与目录约定
Phase 1：快速模式真实检测 + source_clip.mp4 最小闭环
Phase 2：TransNetV2 高精模式 + fallback
Phase 3：片段导出与文件操作
Phase 4：真实关键帧抽取
Phase 5：进度事件、调试产物、内置 Python runtime
```

默认 ffmpeg 策略：

```bash
ffmpeg -y -ss {startSeconds} -i source.mp4 -t {durationSeconds} \
  -map 0:v:0 -map 0:a? \
  -c:v libx264 -preset veryfast -crf 18 \
  -c:a aac -b:a 128k \
  -pix_fmt yuv420p -movflags +faststart \
  source_clip.mp4
```
