### 4.1 UI / 交互（用户反馈 + 已知债）

| 类别 | 现象 / 改进方向 | 建议优先级 |
| --- | --- | --- |
| **整体审美** | 三栏已可拖拽；用户仍觉侧栏/中栏/右栏观感待抛光 | **中**（P5 / issue 10 后） |
| **支撑阶段中栏** | reference 等曾出现提交区与占位混用；现以 `ScenePrepSupportWorkspace` 为主，**布局密度、按钮层级、与 gate 表单一致性**待统一 | **中** |
| **Core 工作区** | MVP 占位 + 运行 + 提交 + 策略 + FlowActions **堆叠**，主按钮非全宽等需按 `DESIGN.md` 再梳 | **中** |
| **产物检查器** | 无产物时空态；多阶段切换时选中产物逻辑可再清晰 | **低** |
| **侧栏** | 「请先完成 xxx」小字、阻塞样式、`entryPath` 下 intake **可跳过/折叠**文案未做全（DESIGN §1.3） | **中** |
| **字阶与 token** | 子标题/说明字阶已改一轮；全量扫 `sceneforge/**/*.module.css` 硬编码 | **低** |
| **错误提示** | 提交/校验失败 `Alert` 位置与堆叠；与底部任务进度关系 | **低** |
| **Continue 语义** | 用户曾期望「继续=自动 AI」；现为审批+切阶段 — **产品文案**可再解释 | **低**（文案） |
