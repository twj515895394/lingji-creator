## 本轮已完成的系统优化与体验重构清单

### 1. 资产处理工作台双栏解耦与技术信息收纳
*   **页面重构**：将工作台主框架从三栏修改为双栏（`.twoColumnShell`，左步骤 + 中间内容，只占 208px + 1fr），彻底隐藏右侧无交互面板，最大化释放编辑宽度。
*   **折叠式技术信息**：原右侧栏的“源文件”、“素材编号”等只读属性收纳至工作区最底部的 `<details>` 折叠块（“技术信息”）中，默认折叠，需要时点击展开，首屏极为清爽。

### 2. 视频与步骤操作纵向堆叠
*   **排版调整**：摒弃了原本“左边视频、右边步骤表单”导致严重横向挤压变形的排版。重构为“上方 16:9 全宽视频大窗、下方全宽步骤操作面板”的垂直上下布局，让时间轴与关键帧展现极具张力。

### 3. 时间轴（SegmentTimeline） contiguous 胶片化与非线性对齐
*   **胶片化拼接**：缝合了镜头段之间原有的断裂感（`gap` 缩减为 `1px`，移除了各段的圆角），呈连续的电影胶带样式。
*   **内阴影描边**：激活态改用内阴影 `box-shadow: inset 0 0 0 1.5px #d6a95f`，完美解决了高亮状态切换引起的任何布局跳动。
*   **非线性播放头对齐**：由于镜头段根据 duration 进行了防压迫非线性拉伸（`.flexGrow`），原线性时间百分比播放头会与镜头段严重偏位。重构了 `playheadPercent` 算法，在 [SegmentTimeline.tsx](file:///Users/tangwujun/Documents/trae_projects/lingji-creator/src/sceneforge/remix/components/SegmentTimeline.tsx) 中累加当前播放位置之前各段的 flex 占比及段内进度占比，使**蓝色播放线与黄色高亮选中框视觉精确对齐**。

### 4. 镜头拆分逻辑 50/50 居中拆分兜底
*   **边界保护**：如果播放指针位于当前镜头段的首尾 1000 毫秒（1 秒）以内（例如刚选中该段时播放头默认停留在起点），点击“在当前播放点拆分”会自动进行 **“对半平分”**（50/50 拆分），避免原逻辑因位置停留在起点而切出 0.6 秒极短碎片垃圾段的问题。

### 5. 快速/高精切片粒度控制
*   **设置项打通**：在 `RemixAssetProcessing` 状态中加入 `granularity`，并与后端契约参数 `minShotDurationMs` 贯通。
*   **macOS 下拉组件**：在模式选择器右侧新增了“最小镜头长度”选择下拉菜单：
    *   `精细` (fine) $\rightarrow$ 对应限制最少 1.0 秒。
    *   `均衡` (balanced) $\rightarrow$ 默认值（由后端快速/高精参数内置控制）。
    *   `较粗` (coarse) $\rightarrow$ 对应限制最少 3.0 秒。
    *   这为用户提供了一键过滤掉太碎、太短片段的控制入口。

### 6. 控制键视觉层级分离与 Tooltip 说明
*   **模式分段组合**：原先大按钮平铺改造成了包裹于 `.modeToggleGroup` 容器中的紧凑分段选择器（Segmented Control）样式。
*   **主辅色分离**：“运行切片”升级为 `variant="primary"` 蓝色高亮，拉开视觉重点。
*   **配置精简**：庞大的校准保留/覆盖按钮被精简为一个 `<Checkbox>` 控件。
*   **Tooltip 气泡提示**：为模式选择、运行切片、人工校准选项及段落合并、拆分等核心按钮全部加上了 hover 的 `title` 中文功能气泡解释。

### 7. 关键帧按镜头段结构化分组与批量提取提示
*   **按段归纳**：改写了 [KeyframeGallery.tsx](file:///Users/tangwujun/Documents/trae_projects/lingji-creator/src/sceneforge/remix/components/KeyframeGallery.tsx)，将 flat 网格列表调整为按 `镜头段 #01`、`镜头段 #02` 等镜头段徽章和时间段名称分组呈现的小 Section，各段没有提取关键帧时显示虚线框占位符提示。
*   **批量引导**：在头部明确说明“提取关键帧自动为**所有镜头段**一键提取，无需逐个处理”，打消了对超多片段（如 100 个段）需要繁琐操作的恐惧。

### 8. 外围旧术语清理、属性溢出修复与最近项目冗余处理
*   **属性对齐**：资产详情侧栏属性行由 grid 改为普通的 `flex` 左右对齐，彻底解决了特定宽窄分辨率下溢出引起的空白和横向滚动条 Bug。
*   **去冗余**：当项目名与文件夹名一致时，隐藏卡片底部冗余的路径信息。
*   **术语规范**：外围入口和 Setup / Toolbar 中的残留英文 `Remix Mode` 统一收拢至中文 `Remix 二创`，`Source Asset` 统一收拢至 `源素材`。
