## 6. 产品决策备忘（下一代理勿擅自改语义）

1. **Continue**：当前实现 = Validate 通过 → Continue = **审批（若需要）+ 切换到下一阶段**；下一阶段需用户或 Agent **再运行本阶段**，非自动 LLM。  
2. **确认风格 ≠ 自动生成下游产物**。  
3. **entryPath**：`topic_gate` 可跳过 intake **依赖**；`source_intake` **不省略** topic_gate。  
4. **产物展示**：侧栏 **只有阶段**；产物列表与预览在 **右侧检查器**（2026-06-19 用户确认 bug）。  
5. **测试优先占位链**；UI 大抛光等用户明确再开。  
6. 主交付改动习惯：**PRD + 设计/ADR + IMPLEMENTATION-PLAN + issues** 再编码（用户已多次强调）。
