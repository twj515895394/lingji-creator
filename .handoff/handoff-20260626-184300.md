## 2. 后续关注点 (Next Focus: Testing Understanding Phase)

用户下一阶段的核心目标是**测试资产入库流程中的“原片理解”功能**。

### 2.1 原片理解相关核心文件
* **后端提取服务**：[remix-understanding-service.ts](file:///Users/tangwujun/Documents/trae_projects/lingji-creator/electron/sceneforge/remix/remix-understanding-service.ts)
  * 该服务通过 LLM 接口阅读 SRT/VTT 文本与切片信息，为每个 Segment 生成视觉摘要、机位描述、台词摘要及二创意图分析。
* **物理资产路径**：
  * 宏观原片理解摘要写到 `sceneforge/remix/source-assets/<sourceAssetId>/analysis/source_overview.md` 与 `.json`。
  * 单片段二创理解写到 `sceneforge/remix/source-assets/<sourceAssetId>/analysis/segment_analysis.md` 与 `.json`。
* **前端展示组件**：[SourceOverviewPanel.tsx](file:///Users/tangwujun/Documents/trae_projects/lingji-creator/src/sceneforge/remix/components/SourceOverviewPanel.tsx)

### 2.2 推荐的测试流程与准备工作
1. 启动本地 Electron 环境（运行根目录下的 `./dev.sh` 脚本）。
2. 在导入视频资产、核对镜头切片，并提取完关键帧后，在工作流导航中点击进入 “**原片理解**” 步骤。
3. 点击 **“生成原片理解”**，观察 LLM 调用情况，查看控制台输出以确保无 API Key 报错。
4. 生成完毕后，重点校验：
   * 界面上的“剧情脉络”和“镜头分段意图”是否渲染得体。
   * 项目物理目录下的 `.md` 和 `.json` 文件是否已经正确回写和保存。
