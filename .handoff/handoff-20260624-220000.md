## 7. Electron 黄金路径实机 Checklist（#7–#14，约 30–45 分钟）

**前置**：`npm run dev`（或项目惯用 Electron 开发命令）；本机 **LLM binding** 已配置（理解/策略/Design/Seedance）；准备 **1 段短视频**（可短于 30s 以省时间）；打开 **SceneForge 工程目录**（`projectDir`）。

**记录方式**：每项勾选 `[ ]` → `[x]`；失败记「步骤号 + 现象 + 控制台/主进程报错摘要」。

### 7.1 工程与资产入库（Phase 1 / #7 #8 #14）

- [ ] **1** 从首页进入 Remix（资产入库意图），已打开 SceneForge 工程；资产库 **非** mock 数据（列表来自 IPC 或空列表+可导入）
- [ ] **2** 点击 **导入新原片**，选择本地视频；导入成功后进入或跳转 **处理页**，源文件路径显示合理（可截断）
- [ ] **3** **运行切片** 成功，Segment 列表/时间轴更新；点击片段可 seek 预览
- [ ] **4** **提取关键帧** 成功，图库有首/尾帧（长片段可有 middle）
- [ ] **5** **生成原片理解** 成功，结构化摘要可读（非整页 raw dump）
- [ ] **6** **人工标注**：至少 1 个标签 + 备注 → **保存**；刷新或重进处理页 **标签/备注仍在**；**保存入库** 成功；资产库状态为 **已入库**，标签筛选生效

### 7.2 Variant 与创作前半（Phase 2 / #9 #10 #13）

- [ ] **7** 资产库选中已入库素材 → **创建二创版本** 或侧栏 **继续创作**；进入 Creation Workspace
- [ ] **8** 步骤 2：配置 Variant（名称/概念/保留矩阵等）→ **保存配置** 无报错
- [ ] **9** **生成改编策略**、**Remix Design**、**关键帧改图 Prompt** 依次成功；提示词可 **复制** 并有反馈
- [ ] **10** 返回资产库：侧栏见 **多个 Variant**（若已复制）；**复制** Variant 后列表增加；**继续创作** 进入对应 Variant；**重命名** 后名称同步（可选：**删除** 副本且 Source 仍在）

### 7.3 改后帧、Seedance、导出（Phase 3 / #11 #12）

- [ ] **11** Creation **改后关键帧** 步：为必需帧 **上传/选择** 图片；状态设为 **已通过 (approved)**；进度显示 x/x
- [ ] **12** 在未全部 approved 时，**Seedance** 步「生成视频提示词」应 **禁用** 并提示门禁文案；全部通过后 **可点击**
- [ ] **13** **生成视频提示词** 成功；预览含结构化字段（画面/镜头/声音等）；可复制 Markdown/纯文本
- [ ] **14** **发布清单** 项与预期一致（策略/Design/关键帧/Seedance 等）；**导出 ZIP**（或文件夹）选路径成功；打开 bundle **无断链**（json/md/关键帧相对路径合理）
- [ ] **15** 关闭工程 → 最近项目打开 → 回到 **合理 Remix 路由**（资产库或上次 Creation/处理页，与 recent identity 一致）

### 7.5 常见失败速查

| 现象 | 优先排查 |
|------|----------|
| 页面空白或「请先打开项目」 | 是否先 **打开 SceneForge 工程** 再进 Remix |
| 导入/切片失败 | FFmpeg、视频路径权限、`errorMessage` 文案 |
| 理解/策略/Design/Seedance 失败 | LLM 配置、额度、主进程日志 |
| 仍像 mock 固定剧情 | 是否误设 `VITE_SCENEFORGE_REMIX_API_MODE=mock` |
| 导出无反应 | `projectDir`、保存对话框取消、见 Creation 顶部错误条 |
