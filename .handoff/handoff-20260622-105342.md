## 增量修改与状态真相

### 1. 修复 Logo 导入路径与 Vite 崩溃
- **问题**：之前在 `SceneForgeStudioHeader.tsx` 中导入横版 Logo 时，相对路径误写成了 `../../assets/`，导致 Vite 无法在 `src/sceneforge/assets` 目录下找到图片而导致页面编译崩溃。
- **解决**：修正为 `../../../assets/sceneforge-logo-horizontal.png`（从 `studio/` 目录向上追溯三级到 `src/assets`）。

### 2. 动态管线状态指示器（“已就绪”动态化）
- **改造前**：头部右侧的「已就绪」标签（statusPill）是完全静态的。
- **改造后**：
  - 绑定了 `useSceneStageRunSessionStore`，若当前有任意阶段处于 `running` 或 `submitting` 状态，标签会动态展示为**「生成中…」**，文字呈现高亮天蓝色，并且左侧的 `Loader2` 图标应用了 CSS 平滑旋转动画。
  - 若整个项目检测为完成态（`projectState?.state.status === 'completed'`），标签会展示为**「已完成」**并配合绿色 `CheckCircle2` 图标。
  - 闲置状态下默认展示为 **「已就绪」**。
- **全局连接状态指示器**：右下角状态栏的「未连接/已连接」是由 `useAgentStore` 控制的全局 MCP/PTY 底层进程通信连接灯，是真实动态状态。

### 3. Logo 背景去白透明化处理（Transparent Overlay）
- **问题**：用户提供的最新 Logo 图片带有纯白背景，在编辑器的 Dark Mode 下显示为一块不协调的白色矩形，且 "Scene" 字样为黑灰色，直接融入背景导致看不清。
- **解决**：我们编写了 Python PIL 处理脚本，对 Logo `ChatGPT Image 2026年6月21日 22_54_40.png` 进行了去白处理：
  - 将背景纯白区域（`avg > 230` 且饱和度极低）转为完全透明。
  - 对边缘防锯齿过渡带进行 `Linear Alpha Blending` 融合。
  - 最终转换为完全透明背景的 `.png`。
- **矢量化升级（最终形态）**：为了彻底解决位图在 Retina 屏幕下的微小锯齿感和暗色主题下的完美辨识度，我们最终在 [SceneForgeStudioHeader.tsx](file:///Users/tangwujun/Documents/trae_projects/lingji-creator/src/sceneforge/components/studio/SceneForgeStudioHeader.tsx) 中移除了外部 `.png` 图片加载，改为**直接在 React 中编写渲染 inline SVG**：
  - 左侧相机定位框和光圈叶片使用鲜明的 `#38BDF8` 天蓝色。
  - 单词 `Scene` 使用纯白文字（`#FFFFFF`）进行重加粗；`Forge` 使用天蓝色（`#38BDF8`）重加粗，使其在黑色背景下极具设计感与辨识度。

### 4. 头部组件布局比例与字号微调
- **Logo 偏左微调**：为 SVG Logo 增加了 `margin-left: 8px`，在头部区域最左侧留出恰当的呼吸边距。
- **分隔线 `/`**：字号从 18px 缩小到 14px，并拓展左右边距（`margin: 0 8px`）。
- **主标题「创作流水线」**：字号由 18px 缩小到 14px，与 36px 渲染高度 of Logo 达成完美的高宽平衡比例。
- **说明文字**：字号缩小到 11px，作为微小辅助文字，整体排版更加紧凑、专业。
