# SceneForge Publish Workspace 文档包计划

**Goal:** 为 publish 阶段补齐完整文档包、执行记录与 issue 状态同步，明确它作为“发布准备工作区”的边界，而不是自动发布系统。

### Phase 1: 现状复核
**Status:** complete

- 复核 publish 在阶段定义、能力表和 Studio 中的当前占位状态。
- 确认文档包与代码现实一致。

### Phase 2: 执行记录补齐
**Status:** complete

- 新建本包的 `task_plan.md`、`findings.md`、`progress.md`。
- 切换 `.planning/current` 指向本包记录。

### Phase 3: issue 收口
**Status:** complete

- 将 publish-workspace 包内 issues 标记为 `completed-local`。
- 在评论中记录当前代码侧仍为占位、文档定义已完成。

### Phase 4: 关联确认
**Status:** complete

- 确认它在 follow-on index 中可被后续会话正确发现。
