# SceneForge Studio UX Clarity — 详细设计

> 日期：2026-06-18  
> 状态：已定稿  
> PRD：`.scratch/sceneforge-studio-ux-clarity/PRD.md`

## 1. 目标

补齐当前容易误导用户的 Studio 文案与入口，让维护者能清晰分辨：

- Continue 与 Continue & Run
- MVP 占位与真实 Direct LLM
- 阶段支持的 Runner 与不支持的 Runner

## 2. 范围

- Core MVP 占位 UX
- Continue 产品文案
- Runner 能力下拉与说明文案

## 3. 设计原则

- 优先澄清语义，而不是新增复杂交互。
- 文案必须与真实能力表一致。
- 不把“实验性 / 占位 / 仅流程验证”伪装成“已完成真实 AI 能力”。
