# 03 - Remix 工作台布局与视觉系统技术方案

日期：2026-06-24  
适用分支：`sceneforge2.0-remix`  
对应问题：P0-04、P0-05、P1-01、P1-02、P1-04、P2-01、P2-02  
主目标：把当前偏“概念稿/营销页”的 Remix 界面改回专业桌面创作工具的工作台秩序，并彻底解决长文件名、右侧横向滚动、按钮层级混乱等问题。

---

## 1. 背景

录屏中最直观的问题有两个：

1. 处理页顶部 Hero 信息卡在长文件名场景下溢出、挤压、断行难看。
2. 右侧详情栏出现横向滚动和内容裁切。

这不是单个 CSS bug，而是布局策略不适合高频工具场景：当前三栏结构、装饰性卡片、大段说明文和长字段一起出现，导致中间主工作区没有成为真正主角。

---

## 2. 设计目标

1. 中间主工作区优先，左侧和右侧退回服务角色。
2. 任何面板不允许横向滚动。
3. 长文件名、长路径、长 ID 必须有统一截断策略。
4. 每个页面只保留一个主 CTA。
5. 视觉语言从“营销卡片”转为“生产工具”。
6. 中文作为默认语义层，英文术语只在必要时保留。

---

## 3. 推荐布局

### 3.1 资产处理工作台

```text
┌────────────────────────────────────────────────────────────┐
│ 顶部：项目 / 素材 / 当前状态 / 轻量 meta                  │
├──────────────┬───────────────────────────────┬─────────────┤
│ 左：步骤导航 │ 中：视频预览 + 当前步骤结果    │ 右：Inspector│
│ 180-220px    │ 自适应，优先占宽              │ 280-320px    │
└──────────────┴───────────────────────────────┴─────────────┘
```

中间区域建议再拆：

```text
视频预览区
切片时间轴 / 关键帧 / 理解结果 / 标注表单
```

### 3.2 资产库

```text
顶部：项目资产库 + 导入按钮 + Tab
Tab：已入库资产 / 处理中 / 异常
主区：卡片网格或任务列表
右侧：选中项 Inspector
```

正式资产卡和处理任务卡不要混用。

---

## 4. 关键 CSS 规则

### 4.1 禁止横向滚动

所有 panel：

```css
.panel,
.panelContent,
.detailRail,
.detailRow,
.heroMetaValue {
  min-width: 0;
}

.panel {
  overflow-y: auto;
  overflow-x: hidden;
}
```

### 4.2 长文本策略

```css
.truncateOneLine {
  min-width: 0;
  overflow: hidden;
  white-space: nowrap;
  text-overflow: ellipsis;
}

.clampTwoLines {
  display: -webkit-box;
  -webkit-line-clamp: 2;
  -webkit-box-orient: vertical;
  overflow: hidden;
}

.breakTechnicalValue {
  overflow-wrap: anywhere;
  word-break: break-word;
}
```

使用原则：

| 内容 | 展示策略 |
|------|----------|
| 素材标题 | 最多两行 |
| 文件名 | 一行截断 |
| 完整路径 | 默认不展示，放 tooltip / 技术信息折叠区 |
| ID | 默认隐藏，复制按钮展示 |
| 备注 | 正文区域展示，不挤在右栏 row |

---

## 5. 顶部 Hero 改造

当前问题：顶部四个窄信息卡会在长文件名下崩。

建议改成：

```text
素材处理工作台
素材标题最多两行
未入库 · 当前步骤：人工标注 · 2:04 · 1920×1080 · 3 段 · 9 帧 · 最近更新 2026-06-24
```

不再用四张 meta card。完整路径进入右侧“技术信息”折叠区。

---

## 6. 右侧 Inspector 改造

右侧只显示当前决策需要的信息：

```text
状态
- 生命周期：待确认
- 当前步骤：人工标注
- 阻塞原因：人工标注未保存

下一步
- 保存人工标注后可保存入库

操作
- 主动作：保存人工标注
- 次动作：返回处理中队列
```

不要重复完整素材档案，不要展示长 ID。

---

## 7. 按钮系统

### 7.1 页面级主动作

| 页面 | 主动作 |
|------|--------|
| 已入库资产库 | 创建二创 / 导入新原片 |
| 处理中队列 | 继续处理 |
| 处理页 | 完成当前步骤 |
| 待确认页 | 保存入库 |
| Creation Workspace | 生成当前阶段产物 |

### 7.2 按钮层级

- Primary：每屏最多一个。
- Accent：用于当前步骤关键动作。
- Outline：次级动作。
- Ghost：查看详情、取消、返回。
- Destructive：删除草稿、删除 Variant。

---

## 8. 术语统一

| 当前 | 建议 |
|------|------|
| Source Asset | 原片资产 / 源素材 |
| Variant | 二创版本 |
| Segment | 镜头段 |
| Remix Mode | Remix 二创 |
| Processing | 处理中 |
| Published to Library | 已入库 |

页面里不要出现 `Source Asset 处理工作台` 这类中英混排标题。

---

## 9. 验收标准

- [ ] 处理页顶部长文件名不溢出、不重叠。
- [ ] 右侧 Inspector 不出现横向滚动。
- [ ] 资产库卡片长标题最多两行。
- [ ] 完整路径不直接占据主视觉位置。
- [ ] 每屏只有一个主 CTA。
- [ ] 中英混排术语明显减少。
- [ ] 中间主工作区承载主要内容，不再被左右栏抢占。
- [ ] 资产库与处理页在视觉上区分正式资产和处理任务。

---

4. 拆正式资产卡和处理任务卡。

7. 加长文本回归测试和截图验收。
