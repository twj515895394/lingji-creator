# Issue 03b：单片段音频 ASR 重跑

## 目标

在片段级卡片上提供“单片段音频 ASR 重跑”能力，让用户在只对某一段台词不满意时，可以基于当前 ASR 选择直接重跑该片段 transcript。

## 范围

- 片段卡片上的操作入口
- 单段 ASR IPC / 服务调用
- 单段重跑后的局部刷新与 loading 反馈

## 必须产出

- 每个片段卡片可触发单段 ASR 重跑
- 读取 Issue 01 的统一 `preferredAsrEngine`
- 单段重跑完成后只刷新对应片段 transcript，必要时再触发最小范围的下游 stale 标记

## 硬规则

- 不要求重跑全量片段作为前置
- 不能引入第二套 ASR 方式选择
- 重跑反馈要局部化，不能让整个页面都像跑总任务一样锁死

## 验收

- 任一片段可以独立重跑 ASR
- 单段重跑后对应片段 transcript 更新
- 定向测试能断言当前所选引擎被正确透传
