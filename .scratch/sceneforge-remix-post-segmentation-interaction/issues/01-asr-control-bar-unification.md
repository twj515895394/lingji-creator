# Issue 01：ASR 控制栏统一样式与单一状态源

## 目标

把当前原片理解区的 ASR 引擎选择入口改成和 Remix 现有界面一致的组件样式，并把它明确收口为切片后阶段唯一的 ASR 选择来源。

## 范围

- `原片理解` 区域顶部控制栏 UI
- ASR 引擎的本地状态持有与透传方式
- 为后续“全部片段音频 ASR 重跑 / 单片段 ASR 重跑”提供统一读取入口

## 必须产出

- 一个风格与现有按钮/面板一致的 ASR 选择器
- `preferredAsrEngine` 的单一状态源
- 对全量理解、全量 ASR 重跑、单段 ASR 重跑的一致透传契约

## 硬规则

- 不新增第二个 ASR 选择入口
- 不继续使用原生 `<select>` 的默认系统样式作为最终交付
- ASR 选择值必须可以被后续所有 ASR 相关动作复用

## 验收

- 当前页面中，ASR 选择区的视觉样式与周围操作栏统一
- 切换 ASR 后，`生成原片理解` / `全部片段音频 ASR 重跑` / `单片段 ASR 重跑` 都使用同一选择值
- 定向 UI/交互测试通过
