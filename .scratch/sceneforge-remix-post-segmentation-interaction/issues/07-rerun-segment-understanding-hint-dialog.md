# Issue 07：「重跑本段理解」弹窗补充提示与 prompt 注入

## 父问题

延续交接：[.handoff/handoff-20260629-170233.md](../../../.handoff/handoff-20260629-170233.md) · 问题 3（重跑本段前先弹补充、只重跑多模态理解、不影响 ASR）。

## 要构建什么

用户点击单段「重跑本段理解」（按钮文案从易误解的「重跑本段」收口）时，先弹出轻量对话框：可填写 **用户补充建议**（可为空），说明 **仅重跑该段 LLM/多模态理解，不会重跑 ASR**。确认后调用现有单段理解重跑链路，并将本次补充作为 **一次性 rerun hint** 注入该次 prompt（不默认持久化到工程文件）。

端到端：点按钮 → 弹窗 → 确认 → 重跑进行中状态与结果展示与现有一致；未填补充时行为等同于「空补充」重跑。

## 验收标准

- [ ] 按钮与辅助文案明确区分「重跑 ASR」与「重跑本段理解」
- [ ] 弹窗可跳过内容直接确认；补充内容进入当次 segment understanding 的用户提示块
- [ ] 单段 ASR 重跑入口与逻辑未被本改动触发或覆盖
- [ ] IPC/类型契约与 preload、渲染层 API 一致（若新增 hint 字段则三处同步）
- [ ] 定向 vitest 覆盖弹窗确认与 hint 透传（或等价交互测试）；`npx tsc --noEmit` 通过
