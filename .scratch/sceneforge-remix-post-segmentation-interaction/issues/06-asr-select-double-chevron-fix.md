# Issue 06：ASR 引擎下拉去除双箭头样式冲突

## 父问题

延续交接：[.handoff/handoff-20260629-170233.md](../../../.handoff/handoff-20260629-170233.md) · 问题 2（双下拉标识、大小不一致）。

## 要构建什么

原片理解区 ASR 引擎选择器在视觉上只保留 **一套** 下拉指示（与项目统一 `Select` 一致），不再出现组件内 Chevron 与 CSS 背景箭头叠加导致的「两个箭头、大小不同」。

端到端：用户打开 Remix 原片理解控制栏 → 选择 ASR 引擎 → 下拉触发器外观与周围操作栏一致、箭头单一且对齐。

## 验收标准

- [ ] ASR 选择触发器上仅可见一套下拉指示（无重复箭头）
- [ ] 保留边框、圆角、颜色等皮肤样式，与相邻按钮/面板协调
- [ ] 切换引擎后行为不变（仍读写同一 `preferredAsrEngine`）
- [ ] 相关页面/组件测试仍通过；`npx tsc --noEmit` 通过
