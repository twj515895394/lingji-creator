# 参考分析阶段 · 用户提示

仅使用以下 Stage Context，不要读取未列出的项目文件：

{{stageContext}}

返回 JSON 对象，其中 `reference_notes` 是完整 Markdown。不要返回额外 artifact。

`reference_notes` 须包含以下**中文小节**（`##` 标题用中文，不要用英文 section 名作标题）：

- 参考类型
- 决策摘要
- 创意方向上下文
- 参考边界（含主参考、辅助参考）
- 允许继承
- 禁止继承
- 必须保留
- 应当保留（可选）
- 允许重写与微调的范围（可选）
- 必须避免
- 风险说明
- 下一步行动

正文以中文撰写；英文仅用于必要参数名、风格 ID 或极短专业锚点。请写成正式 Markdown 小节，方便下游直接消费，而不是散文化说明。
