# Script Review Checklist

- 分段与故事节拍或选题时长一致，无结构性遗漏。
- 正式包含 `script_summary`、`segment_strategy`、`story_beats`、`beat_table`、`video_generation_unit_plan`、`script_body`、`performance_handoff`、`storyboard_handoff`、`risk_notes`、`next_action`。
- `segment_strategy` 必须写出 `segment_duration_seconds` 与各段 `segment_time_range`，不能只写“分三段推进”。
- `story_beats` 不只是标题骨架，至少能看出 beat 的剧情推进与动作/情绪锚点。
- `video_generation_unit_plan` 能让 storyboard 直接继承，不是空壳 VGU 列表；至少应显式给出 `pacing_profile` 与 `shot_density_hint`。
- 旁白/对白可录制，无与设计提示词重复的冗长视觉描写。
- `script_body` 至少包含两个可拍段落，并给出动作、停顿、视线或节奏锚点。
- `performance_handoff` 明确指出下游必须继承的动作、停顿、reaction timing。
- `storyboard_handoff` 明确指出镜头关注点、站位/道具连续性或转场承接，并显式写明 `boundary_lock / 镜头不得跨段`。
- 服从设计主参考的气质与角色边界，无越界 IP 照搬。
- 动作与情绪提示可供 performance 阶段直接使用。
- 未越界写成分镜 pack 或视频提示词。
